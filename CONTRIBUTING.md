# Как внести вклад в проект | Contributing Guide

Спасибо за интерес к проекту! Мы приветствуем любой вклад в развитие проекта эскалатора SOLIDWORKS.

## 🚀 Способы участия | Ways to Contribute

### 1. Сообщения об ошибках | Bug Reports
- Используйте [GitHub Issues](https://github.com/Heigen007/solidworks_escalator/issues)
- Подробно опишите проблему
- Укажите версию SOLIDWORKS
- Приложите скриншоты при необходимости

### 2. Предложения улучшений | Feature Requests
- Создайте Issue с меткой "enhancement"
- Опишите желаемую функциональность
- Объясните, почему это будет полезно

### 3. Улучшения кода | Code Improvements
- Оптимизация существующих деталей
- Добавление новых компонентов
- Улучшение сборок
- Создание дополнительных чертежей

## 📋 Процесс внесения изменений | Contribution Process

1. **Fork** проекта
2. **Создайте** ветку для ваших изменений (`git checkout -b feature/amazing-feature`)
3. **Сделайте** изменения в SOLIDWORKS файлах
4. **Зафиксируйте** изменения (`git commit -m 'Add amazing feature'`)
5. **Отправьте** в ветку (`git push origin feature/amazing-feature`)
6. **Откройте** Pull Request

## 🎯 Стандарты качества | Quality Standards

### Файлы SOLIDWORKS
- Используйте понятные имена файлов
- Добавляйте описания к деталям и сборкам
- Следуйте единому стилю моделирования
- Оптимизируйте модели для производительности

### Документация
- Обновляйте README при добавлении новых компонентов
- Создавайте чертежи для новых деталей
- Добавляйте комментарии к сложным сборкам

## 🔧 Технические требования | Technical Requirements

- **SOLIDWORKS:** версия 2018 или новее
- **Формат файлов:** сохраняйте в версии 2018 для совместимости
- **Единицы измерения:** миллиметры (мм)
- **Материалы:** используйте стандартные материалы из библиотеки SOLIDWORKS

## 📐 Соглашения по именованию | Naming Conventions

### Детали (.SLDPRT)
- `ComponentName.SLDPRT` - для основных компонентов
- `AssemblyPart.SLDPRT` - для частей сборок

### Сборки (.SLDASM)
- `MainAssembly.SLDASM` - для основных сборок
- `SubAssembly.SLDASM` - для подсборок

### Чертежи (.SLDDRW)
- `ComponentName.SLDDRW` - чертеж соответствующей детали

## 🤝 Кодекс поведения | Code of Conduct

- Будьте уважительны к другим участникам
- Конструктивно обсуждайте технические вопросы
- Помогайте новичкам разобраться в проекте
- Следуйте принципам открытого исходного кода

## 📞 Связь | Contact

- Создайте [Issue](https://github.com/Heigen007/solidworks_escalator/issues) для обсуждения
- Укажите подробное описание предложения
- Ответим в течение 2-3 дней
